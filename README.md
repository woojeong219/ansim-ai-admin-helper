# 군포시 AI 업무 도우미

외부 AI API 없이 실행되는 행정업무 지원 웹앱 프로토타입입니다.

## 엑셀 자동화 기능

- 여러 파일과 모든 시트를 열 이름 기준으로 합치기
- 중복, 필수값 누락, 숫자·날짜 형식 오류 찾기
- 초보자도 이해하기 쉬운 점검 항목 설명과 선택 예시
- 최대 3개 조건별 건수·합계·평균·최대·최소 집계
- 집계 기준 열과 계산 열의 중복 선택 방지 및 숫자 열 자동 추천
- 필요한 열 선택, 순서 지정, 열 이름 변경, 정렬
- 제목·빈 행이 있는 각 파일에서 기준 열 행과 열 이름을 자동 인식
- 파일·시트별 기준 열 행을 사용자가 직접 수정 가능
- 인식된 전체 열 중 결과 열과 순서를 자유롭게 선택
- 서로 다른 서식은 열 이름으로 맞추고 없는 열은 빈칸으로 표시
- 다중 정렬 기준 선택과 원하는 번호 열 자동 재부여
- 업무별 결과를 엑셀 파일로 다운로드
- 엑셀 VBA 코드 적용 매뉴얼과 VBA 기초 설명
- 사용자 입력에 따라 바뀌는 AI 프롬프트 자동 작성
- VBA 코드를 Excel에 적용·실행·저장하는 단계별 매뉴얼
- 안전한 VBA 예제, 보안 점검표, 자주 발생하는 오류 해결 안내
- AI 엑셀 활용 방법: 데이터 구조, 원하는 결과, 실행 환경을 설명하는 방법
- 잘못된 요청·올바른 요청 비교, 완성 예시와 복사용 요청 틀

## 기타 기능

- 보도자료·업무보고 기본 초안 생성과 연락처·주민등록번호·이메일 마스킹
- 공문 작성, 예산 지출, 출장, 물품 구매, 민원 응대에 관한 신입공무원용 기본 안내

## 문서 변환

- 엑셀·Word·HWP를 PDF로 변환
- HWP를 Word로 변환
- 이미지 여러 장을 하나의 PDF로 변환
- PDF에서 표를 Excel로, 본문을 Word로 추출
- PDF 페이지를 PNG 이미지로 변환
- PDF 여러 개를 하나로 합치기
- PDF→HWP의 기술적 제약과 기관 PC에서의 안전한 대안 안내
- PDF→Word·Excel과 HWP→Word에서 `원본 모습 우선` 또는 `내용 편집 우선` 선택

`원본 모습 우선`은 페이지를 이미지로 삽입해 그림·표·배치를 유지하지만 내용을 직접 편집하기 어렵습니다. `내용 편집 우선`은 글자와 표를 추출해 수정하기 쉽지만 복잡한 서식은 달라질 수 있습니다.

PDF→Word·Excel은 내용 추출 중심이며 복잡한 원본 배치를 완벽히 복원하지 않습니다. HWP 변환 가능 여부는 배포 환경의 LibreOffice 지원 범위에 따라 달라질 수 있습니다.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 새 앱을 생성합니다.
3. 저장소와 브랜치를 선택하고 실행 파일을 `app.py`로 지정합니다.
4. 배포 후 생성된 URL로 접속합니다.

## 개인정보 주의

이 앱은 외부 AI API를 호출하지 않지만, 공개 클라우드에 배포하면 업로드 자료가 해당 웹서버의 메모리를 거칩니다. 실제 개인정보, 비공개 행정자료, 과세자료를 공개 배포판에 입력하지 마세요. 실제 업무 적용 전에는 반드시 기관의 개인정보·정보보안 기준과 승인 절차를 확인해야 합니다.
