# 안심 AI 행정도우미

외부 AI API 없이 실행되는 행정업무 지원 웹앱 프로토타입입니다.

## 엑셀 자동화 기능

- 여러 파일과 모든 시트를 열 이름 기준으로 합치기
- 중복, 필수값 누락, 숫자·날짜 형식 오류 찾기
- 최대 3개 조건별 건수·합계·평균·최대·최소 집계
- 집계 기준 열과 계산 열의 중복 선택 방지 및 숫자 열 자동 추천
- 필요한 열 선택, 순서 지정, 열 이름 변경, 정렬
- 부서별 명단 취합과 중복·누락 점검
- 업무별 결과를 엑셀 파일로 다운로드
- 엑셀 AI 활용 매뉴얼과 VBA 기초 설명
- 사용자 입력에 따라 바뀌는 AI 프롬프트 자동 작성
- VBA 코드를 Excel에 적용·실행·저장하는 단계별 매뉴얼
- 안전한 VBA 예제, 보안 점검표, 자주 발생하는 오류 해결 안내

## 기타 기능

- 보도자료·업무보고 기본 초안 생성과 연락처·주민등록번호·이메일 마스킹
- 공문 작성, 예산 지출, 출장, 물품 구매, 민원 응대에 관한 신입공무원용 기본 안내

## 로컬 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Streamlit Community Cloud에서 새 앱을 생성합니다.
3. 저장소와 브랜치를 선택하고 실행 파일을 `app.py`로 지정합니다.
4. 배포 후 생성된 URL로 접속합니다.

## 개인정보 주의

이 앱은 외부 AI API를 호출하지 않지만, 공개 클라우드에 배포하면 업로드 자료가 해당 웹서버의 메모리를 거칩니다. 실제 개인정보, 비공개 행정자료, 과세자료를 공개 배포판에 입력하지 마세요. 실제 업무 적용 전에는 반드시 기관의 개인정보·정보보안 기준과 승인 절차를 확인해야 합니다.
